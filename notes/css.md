* 在编写 CSS 时：应该优先使用 class 选择器，偶尔使用元素选择器，尽可能避免使用 ID 选择器。

* css继承特性：字体和文本排版相关的属性通常可以被子元素继承，而其他类型的属性通常不会自动继承。

* 表单控件自带样式，因此不会自动继承字体。要实现则需手动指定font: inherit;

```
input,
button,
select,
textarea {
  font: inherit;
}
```

* 十六进制表示颜色，当每组的两个字符相同时，可以简写为一个字符：ff0000 ——> f00

* font-size 一般不使用百分比作为单位

* em 用于 font-size 时，相对于父元素的字体大小；用于 margin、padding 等其他属性时，相对于元素自身的字体大小。
